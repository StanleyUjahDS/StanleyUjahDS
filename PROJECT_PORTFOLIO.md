# Project Portfolio Map

This map groups the public repositories by the capability they demonstrate.
It is intended to make the portfolio easy to review for PhD applications,
blockchain engineering roles, data-science roles, and fintech positions.

## 1. Production blockchain and Web3 systems

### Griot Network — `cowrie_griot`

- **Type:** Live mobile product
- **Area:** Social Web3, wallets, payments, reputation, subscriptions
- **Stack:** Flutter, Dart, Node.js, PostgreSQL, Solidity, EVM, Firebase, AWS
- **Evidence:** 11,000+ registered accounts and published iOS/Android apps
- **Best for:** Blockchain engineer, mobile engineer, fintech, Web3 product roles

### Cowrie Protocol — `cowrie-protocol`

- **Type:** Protocol ecosystem website and dApp entry point
- **Area:** Decentralised applications and Web3 product communication
- **Stack:** React, Vite, JavaScript, CSS
- **Best for:** Web3 frontend, protocol, and technical product roles

### HBADG / Honeybadger repositories

- **Type:** Token and supporting smart-contract work
- **Area:** BEP-20 token infrastructure, EVM payments, rewards, and transactions
- **Network:** BNB Smart Chain
- **Best for:** Solidity, smart-contract, DeFi, and token-infrastructure roles

## 2. Academic blockchain and fintech research

### ChainEquity — `ChainEquity` / `Chain-Equity`

- **Type:** Collaborative MSc enterprise-development project
- **Area:** Equity tokenisation, SME capital raising, investor workflows, and
  blockchain applications in financial services
- **Output:** Research, requirements analysis, solution design, and prototype
- **Best for:** PhD applications, fintech research, blockchain governance, and
  financial-systems roles

## 3. Data science and machine learning

### MSc stock-market prediction — `phdportfolio`

- **Type:** MSc research portfolio
- **Area:** Financial-market prediction and investment-banking analytics
- **Stack:** Python, Pandas, NumPy, Scikit-learn, regression, time-series
  modelling, and sentiment features
- **Research question:** How do machine-learning approaches compare with
  traditional statistical methods for S&P 500 prediction?
- **Best for:** Data scientist, ML engineer, quantitative analyst, and PhD roles

## 4. Mobile and educational software

### Builders Oasis — `builders_oasis`

- **Type:** Flutter product prototype
- **Area:** Educational content, course discovery, learner activity, reminders
- **Stack:** Flutter, Dart, Provider, GoRouter, Hive, secure storage, and local
  notifications
- **Best for:** Flutter, mobile, edtech, and product-engineering roles
